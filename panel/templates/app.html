Подключить новую ноду

Сценарий: нажимаешь одну из кнопок выше, указываешь имя, публичный хост и название в подписке, и получаешь одну bash-команду. На VLESS-ноде установятся Xray + агент, на Hysteria-ноде — официальный hysteria-server + агент; регистрация и первый конфиг завершатся автоматически.

⚡ Нода авто-балансировки — то же самое, но сервер сразу попадает в пул. В подписке такие ноды объединяются в группу «⚡ Auto (Pool)», и клиент (Hiddify / sing-box / Clash / Karing / Happ) сам выбирает самый быстрый узел пула.

🎯 Балансер-нода — отдельный сервер, который получает один vless-ключ и сам внутри выбирает самый быстрый upstream из пула (xray observatory + leastPing). Этот ключ работает в любом клиенте (v2rayN, Shadowrocket, Hiddify). Чтобы ключ был полезен, в пуле (⚡) должно быть хотя бы 2 ноды.

🇷🇺→🌍 Нода обхода (whitelist) — связка из двух серверов. Сначала ставишь обычную ⚡ ноду за границей (Германия / Финляндия / Нидерланды) — это будет «выход». Потом запускаешь эту кнопку, чтобы поставить РФ-фронт на whitelisted IP и сразу прицепить его к иностранному выходу. Пользователи коннектятся именно на РФ-фронт (его IP не дросселируется ТСПУ); xray на фронте пересылает весь трафик одним VLESS+Reality-прыжком в иностранную ноду, которая уже выпускает его в интернет. В подписке/боте видно только РФ-фронт — иностранный выход спрятан.

Подписки

Одна подписка создаёт отдельный ключ на каждой выбранной VLESS Reality или Hysteria 2 ноде и объединяет их в один URL. Plain/base64 содержит нативные URI, а sing-box и Mihomo получают полноценные protocol-aware конфиги.

API

API-токены используются ботами и скриптами для доступа к панели без session-cookie. Передавай в заголовке Authorization: Bearer <token>. Токен виден ОДИН раз в момент создания — сохрани его сразу.
Интерактивная документация строится прямо из актуальной OpenAPI-схемы панели, поэтому содержит все эндпоинты, параметры, тела запросов, модели ответов и коды ошибок текущей версии. Для запросов нажмите Authorize и вставьте API-токен. Также доступны цельный ReDoc и OpenAPI JSON.

Глобальный домен подписок

Используется для всех ботов, у которых не задан индивидуальный домен. Можно с портом, если reverse-proxy не на :443 (там Reality): https://sub.example.com:4443.

Telegram-боты

Если с ключа идёт больше устройств, чем лимит бота, тебе в chat владельца прилетит уведомление с кнопками «Забанить» / «Игнорировать».

Обновить все ноды

Каждая нода получит команду xnpanel update --force: агент подтянет последний коммит из , перезапустит xray-agent.service (на хосте панели — ещё и xray-panel.service). Reality-ключи и UUID-ы клиентов не трогаются — пользователи продолжат коннектиться без ре-импорта ссылок. Ноды обновляются строго по очереди, хост панели — последним. Если агент или GitHub временно недоступен, текущая нода будет автоматически повторяться до подтверждения версии. Очередь можно отменить кнопкой ниже.

Очередь отменена. Уже подтверждённые ноды оставлены обновлёнными, остальные не трогались. Все ноды успешно обновились — фактическая смена коммита подтверждена через /system/version. На части нод агент принял команду, но коммит не сменился за секунд. Скорее всего xnpanel update --force упал в фоне. Зайди по SSH на ноду и посмотри journalctl -t xnpanel-upgrade -n 200, либо запусти sudo /usr/local/bin/xnpanel update --force руками — увидишь причину. Часть нод вообще не ответила агенту. Проверь доступность xray-agent.service и сетевую связность. Хост панели в списке — соединение с панелью на ~10 секунд могло моргнуть, это нормально.

Установочная команда готова

Reality, TCP/gRPC/xHTTP, WARP, собственный SNI и HAProxy-мост. Нативный QUIC/UDP, ACME/TLS, port hopping, obfs, BBR/Reno и traffic stats.

⚡ Попадёт в primary-бакет пользовательской подписки (легаси «in_pool»=true). В подписке — в группе «⚡ Auto (Pool)».

🛡 Попадёт в fallback-бакет. Клиент переключается сюда, если все ⚡ primary недоступны (белые списки в регионе включились). Каждые сек sing-box пробует primary вернуться.

🎯 Это отдельная нода-балансер. После установки она получит один vless-ключ; xray внутри сам будет выбирать самый быстрый upstream из пула по leastPing. В пуле (⚡) должно быть минимум 2 standalone-ноды — иначе балансеру некого выбирать.

Hysteria 2

Один порт или port hopping диапазон. На сервере откроется UDP, агент установит официальный hysteria-server. Salamander включён по умолчанию.

Hysteria 2 работает как standalone-нода, но её можно добавить в пользовательский primary/fallback-пул. Xray TCP-балансировщик не использует QUIC/UDP upstream напрямую.

Nginx и Let's Encrypt будут настроены автоматически. Внешний VPN-порт останется у Xray, а Nginx получит отдельный внутренний порт.

Этот порт уже занят VPN или агентом — выбери другой.

Пока enrollment «pending», любой, у кого есть команда, может добавить ноду под этим именем. Токен одноразовый — после успеха он становится невалидным.

Скопируй команду и запусти её на новом Ubuntu 24.04-сервере под root. Сервер сам появится в панели через 1–2 минуты.
